# راهنمای تیم کاسپین

این پوشه مرجع عملی پروژه است. مسیر پیشنهادی برای عضو جدید تیم:

1. [راهنمای پروژه](PROJECT_GUIDE.md) — نصب، اجرای محلی، معماری و قواعد تغییر.
2. [راهنمای UI Kit](UI_KIT.md) — کامپوننت‌های منتشرشده و روش استفاده از آن‌ها.
3. [مثال‌ها](EXAMPLES.md) — نمونهٔ کوتاه برای هر قابلیت زیرساختی و UI.
4. [راهنمای Delivery](DELIVERY.md) — gateهای انتشار و smoke check.

## قراردادهای مهم

- از Node نسخهٔ درج‌شده در `.nvmrc` و فقط npm استفاده کنید.
- نصب تکرارپذیر: `npm ci`.
- UI Kit فقط از پکیج منتشرشده مصرف می‌شود: `@amirjalili1374/ui-kit@1.10.0`.
- مسیر داخلی یا import از سورس UI Kit مجاز نیست.
- endpoint، DTO، permission code و رفتار صفحه‌های کسب‌وکار را هنگام کار زیرساختی تغییر ندهید.

برای جزئیات فنی bootstrap، authentication، transport و access control به فایل‌های `architecture/` مراجعه کنید.
